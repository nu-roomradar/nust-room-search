# LP ファーストビュー参考調査（2026-11-07）

RoomRadar の LP（`index.html`）のファーストビューを作り直すための下調べ。8 サイトを Playwright（Chromium）で開き、390×844（DPR2）と 1440×900 の最初の画面、390 幅のページ全体を撮って目視した。数値は `getComputedStyle` で読んだもの（メインの h1 と、最初の画面にある主ボタン）。スクショは作業用の一時フォルダにだけ置き、リポジトリには入れていない。サイトの文言や画像は写さず、自分の言葉で書いている。

**調査環境の制約**：この環境はプロキシ経由。Linear は静的ファイルのホスト（static.linear.app）につながらず CSS が読めなかったため、**計測できなかった**（素の HTML が表示されただけ）。Vercel もページ下のほうの画像の一部が読めなかった（ファーストビューには影響なし）。

## 1. Linear（https://linear.app/）— 計測不可

CSS が読めず崩れた状態でしか表示できなかったため、数値は取れていない。分かったのは次のことだけ。

- 背景は近黒（およそ #111）で、ダークテーマが基本。
- 見出しは「何のシステムか」を一文で言い切る英語の長めの一文。その下に一行の補足と、新機能の告知リンク（「New」＋矢印）。
- ナビは Product / Resources のメニュー＋数個のリンク＋ログイン・サインアップ。モバイルではハンバーガー。

見た目の評価は、運営者の端末で直接見て補ってほしい。

## まとめ

### (a) RoomRadar に借りたい要素

1. **見出しは「大きく・字間を詰めて・短く」**（Vercel・Notion・Apple）。英字は -0.05em 前後まで詰めているが、日本語は詰めすぎると読みにくいので -0.01〜-0.02em にとどめ、太さで見せる（Penmark の 700）。
2. **主ボタンは一つ、塗りの pill。副は淡色か枠線**（Vercel・Apple・Notion）。目的が「アプリを開く」一つの LP には最適。
3. **390 では主ボタンを全幅にする**（Vercel・Stripe・Notion）。親指で押しやすく、迷いがない。
4. **見出しの一語を色つきの pill で強調し、点を付ける**（Notion）。RoomRadar なら「空き」を緑の pill＋点にすると、アプリ内の「空き」表示とそのまま意味がつながる。
5. **実際のアプリ画面を見せ、下端で切る**（Notion・Penmark・TimeTree）。ポスターから来た人に「押すと何が出るか」を一目で伝えられる。PC 幅では大きく、スマホ幅では見出し・ボタンの下からのぞかせる。
6. **ライブ感のある小さな一行**（Stripe の動く数字）。「いま 3限・空き教室 ○室」のように**時刻に合わせた一行**を見出しの上に置くと、静的ページでも「いま使える」感が出る（数字はビルド時に入れるか、時間帯ラベルだけにする）。
7. **画面の外側に一つだけ雰囲気の要素**（Vercel の光のにじみ、Stripe の帯）。RoomRadar は背景にごく薄い方眼（教室の平面図・時間割の格子を連想させる）を一枚敷く程度にとどめる。
8. **ボタンの下に小さく条件を書く**（Raycast の動作環境の注記）。「登録不要・無料・ブラウザで開くだけ」を 12px で添えると、押す前の不安が消える。

### (b) どのサイトもファーストビューで避けていること

- 長い説明文。補足は 1〜2 行まで（Stripe の PC 版だけ例外で、その代わり色を落としている）。
- 主ボタンが 3 つ以上並ぶこと。多くても主＋副の 2 つ。
- 機能の箇条書き・料金・よくある質問。スクロールしてから出す。
- いくつもの色を同時に使うこと。主の色は 1 色（＋強調 1 色）。
- 文字の上に強い模様を重ねて読みにくくすること（Raycast・Stripe でも文字の下は暗い・白い部分）。
- 細かいお知らせ類（Apple だけ例外で、地域選択・店舗のお知らせが上に出る。真似しない方がよい例）。

### (c) RoomRadar のファーストビュー案（2 つ）

守ること：「本サービスは、学生が「自主創造プロジェクト」の一環として開発・運営している試験運用中のサービスです。大学が公式に提供するサービスではありません。」を最初の画面に必ず見える状態で置く。「予約」「確保」は使わない。船橋校舎には触れない。外部 CDN は使わない（フォントはローカル同梱か OS のフォント）。動きはすべて `prefers-reduced-motion: reduce` で止める。

#### 案A「明るい・アプリ画面が主役」（いまの LP の明るい配色を引き継ぐ。おすすめ）

ポスター・Instagram から来た人がすぐ「何ができるか」を見て押せることを優先。いまの LP の紙のような地色・緑（駿河台）・青を引き継ぐので、ポスターとも印象がそろう。

**スマホ（390）上から順に**

1. ヘッダー 56px：左にロゴ、右に小さい「アプリを開く」ボタン（高さ 36px、pill、枠線）。ハンバーガーは置かない。
2. 時刻の一行（上余白 24px）：緑の点＋「いま 3限 ・ 駿河台キャンパス」13px / 500 / #6b665a。時刻帯は JS で計算（JS 無効時は「駿河台キャンパスの空き教室」）。
3. h1（上余白 12px）：「いま、**空き**教室<br>すぐ見つかる。」32px / 800 / 行高 1.3 / 字間 -0.01em / #1a1814。「空き」は緑の pill（背景 #dcfce7、文字 #15803d、左に 8px の緑の点、左右 10px の余白）。
4. 補足（上余白 12px）：「タワー・スコラと駿河台校舎の、授業のない教室を時間割から一覧に。」15px / 400 / 行高 1.7 / #6b665a。2 行まで。
5. 主ボタン（上余白 24px）：全幅（左右 16px）、高さ 56px、pill、背景 #16a34a、文字白 17px / 700「空き教室を探す →」。影は y 4px・ぼかし 12px・緑 25%。押したら 0.98 倍に縮む（reduced-motion では無し）。
6. 注記（上余白 8px）：「登録不要・無料・ブラウザで開くだけ」12px / #6b665a、中央。
7. 試験運用の表記（上余白 16px）：薄い枠の小さなカード（背景 #fff、枠 #e7e3d8、角丸 12px、余白 12px）に必須の文言を全文 12px / 行高 1.6 / #6b665a。先頭に「試験運用中」の小さなラベル（橙 #f97316 の枠線 pill）。
8. アプリ画面（上余白 24px）：実際の検索結果画面のスクショを、角丸 28px の端末風の枠（縁 8px、#1a1814）に入れ、幅 300px で中央、**最初の画面の下端で切れる**位置に置く。地の色との境目に薄い影。

390×844 で 1〜7 が確実に入り、8 の上部がのぞく高さに収める（1〜7 で約 640px）。

**PC（1440）**

- 内容の幅 1120px、2 カラム（左 56% / 右 44%）、上下中央そろえ。ヘッダー 64px。
- 左：時刻の一行 14px → h1 56px / 800 / 行高 1.2 / -0.015em（2 行）→ 補足 18px / 行高 1.7（最大幅 30em）→ 主ボタン（高さ 56px、左右 32px、17px）＋右に注記 13px → 試験運用カード（最大幅 480px、13px）。
- 右：端末枠の実画面（幅 340px）を少し傾けず正面で置き、後ろに「空き」状態の教室カード 2〜3 枚を半分重ねる（Notion・TimeTree の重ね方）。カードは白・角丸 16px・影。
- 背景：#f5f3ee の上に 24px 方眼（線 #1a1814 の 4% 不透明）。右カラムの後ろだけ緑の円形のにじみ（#16a34a、不透明度 12%、半径 360px、ぼかし大）。
- 動き：読み込み時に見出し・ボタン・画面が 8px 下から順に出る（0.4 秒、0.06 秒ずつ遅らせる）。時刻の一行の緑の点がゆっくり点滅。どちらも reduced-motion で無効。

**配色**：地 #f5f3ee、文字 #1a1814、補足 #6b665a、主 #16a34a、強調の淡緑 #dcfce7、注意の橙 #f97316（ラベルだけ）。青 #2563eb はリンクのみ。

#### 案B「暗い・夜の教室」（印象重視。Raycast・Linear 寄り）

Instagram のリール・CM と雰囲気を合わせたい場合の案。「空いている部屋に明かりがつく」イメージで、ダークの中に緑の光る点を置く。ただしポスター（明るい紙）との連続性は下がり、注記の小さな文字は暗い地だと読みにくくなりやすいので、コントラストを必ず確保する。

**スマホ（390）上から順に**

1. ヘッダー 56px：左にロゴ（白）、右に「開く」（pill、白い枠 20% 不透明）。ヘッダー自体を角丸 16px の半透明カード（背景 白 6%、枠 白 10%）にして上に浮かべる（Raycast）。
2. 背景：#0b0f0d 一色の上に、教室の平面図を思わせる細い格子（白 5%）。格子のマスのうち数個だけが緑（#22c55e）にぼんやり光り、数秒ごとに別のマスへ移る（reduced-motion では固定の静止画）。
3. 時刻の一行：等幅風の 12px「NOW ・ 3限」#86efac（DM Mono をローカル同梱）。
4. h1：「空いてる教室が、<br>光って見える。」30px / 800 / 行高 1.3 / -0.01em / #f5f5f4。「光って」だけ緑 #4ade80。
5. 補足：「駿河台キャンパスの授業のない教室を、時間割からまとめて表示。」15px / 行高 1.7 / #a8a29e。
6. 主ボタン：全幅、高さ 56px、pill、背景 #22c55e、文字 #052e16（暗い緑）17px / 700「空き教室を探す →」。外側に緑の光（box-shadow 0 0 24px 緑 35%）。
7. 注記：「登録不要・無料」12px / #a8a29e。
8. 試験運用の表記：枠 白 12%・背景 白 4%・角丸 12px のカードに必須文言 12px / #d6d3d1（地とのコントラスト比 4.5 以上を確認）。
9. アプリ画面：画面の下端から、実画面を枠なしで角丸 20px・緑の細い縁取りで半分のぞかせる。アプリ本体が明るい配色なら、そのまま明るいスクショを置く（暗い中の明るい画面は目を引く）。

**PC（1440）**：中央寄せ 1 カラム（Raycast 型）。h1 60px / 800 / 行高 1.15。ボタンは中央に幅 280px。下に実画面を幅 880px で置き、最初の画面の下端で切る。格子の光は画面全体に広げ、文字の後ろは暗く保つ（中央を暗くする放射グラデーションを重ねる）。

**配色**：地 #0b0f0d、文字 #f5f5f4、補足 #a8a29e、主 #22c55e、強調 #4ade80、格子 白 5%。

#### どちらにするか

おすすめは**案A**。理由：ポスター（明るい紙面）・いまの LP と見た目が続き、QR を読んだ人が「さっきのポスターのサービスだ」とすぐ分かる。必須の注記も明るい地のほうが読みやすい。案B の「光る教室」の格子は、案A の PC 版の背景（方眼）に弱めて取り入れることもできる。

#### 実装メモ（どちらの案でも）

- 外部 CDN・Google Fonts は使わない。フォントは OS のもの（Hiragino Sans / Noto Sans JP）か、必要ならサブセット化して同梱。
- 動きは CSS だけで足りる（ライブラリ不要）。`@media (prefers-reduced-motion: reduce)` で animation・transition を止め、光の格子は静止画にする。
- アプリ画面は実際の検索画面のスクショ（`/verify-ui` で撮るもの）を WebP で同梱。端末枠は CSS で描く。
- 390 で横にはみ出さないこと（Penmark で見られた点）、主ボタンが最初の画面に必ず入ることを Playwright で確認する。
