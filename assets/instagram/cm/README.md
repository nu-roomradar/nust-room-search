## 改善メモ（運営からの意見と、残っている課題）

| 版 | 運営の意見 | そのとき直したこと |
|---|---|---|
| v1（写真版） | 使い方の場面はよい。人が使っている場面は写真ではなくリアルな動画にしたい。音楽はもっと陽気に。最後のロゴの注意書きはもっと下に | → v2 で AI 動画・明るい BGM・ロゴのアニメに |
| v2（Pixel 風） | ロゴに対するレーダーの中心がずれている。音声も入れたい。字幕がちゃっちい | 中心を測り直してロゴと一緒に動くように。生の音・効果音を追加。字幕を太字のせり上がりに |
| v3（Vlog 風） | もっと人が作った感じにしたい（映像が原因かも） | 色を自然に・粒子・手持ちの揺れ、画面録画風、手書きの書き込み、Reels 風字幕 |

**次に良くするなら**
1. **人の映像を本物にする。** AI 生成の人物は、よく見ると分かる。v3 の構成のまま、7カットだけ運営メンバーがスマホで撮った5〜8秒の動画に差し替えるのがいちばん効く（顔を出したくなければ手元・後ろ姿でよい）。
2. AI 動画を作り直すなら `video/cm-ai/ai_prompts.md` の「前回わかったこと」を反映する（金色の光を避ける・PC のロゴなし・光の粒なし）。
3. 音楽は Instagram アプリの流行りの曲にすると投稿らしくなる（BGM なし版を使う）。
4. ナレーション（「空きコマ、どこ行く？」など）を入れるなら、運営の声をボイスメモで録って送ってもらう（自然な日本語の声はこちらで作れない）。
5. 投稿したら、どの版を出したか・反応（再生数・保存）をこの README に書き足すと、次の比較に使える。

## 守ること

- **AI 生成の映像を使った版（v2・v3）は、キャプションに「AIで生成した映像」と必ず書く。** 実在の学生に見えるため。
- 船橋校舎を映さない・書かない。「予約」「確保」と書かない（CLAUDE.md ルール3）。
- 動画の最後に「テスト運用中・学生開発の非公式サービスです」を入れてある。消さない（ルール1）。
