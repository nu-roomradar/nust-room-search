## 改善メモ（運営からの意見と、残っている課題）

| 版 | 運営の意見 | そのとき直したこと |
|---|---|---|
| v1（写真版） | 使い方の場面はよい。人が使っている場面は写真ではなくリアルな動画にしたい。音楽はもっと陽気に。最後のロゴの注意書きはもっと下に | → v2 で AI 動画・明るい BGM・ロゴのアニメに |
| v2（Pixel 風） | ロゴに対するレーダーの中心がずれている。音声も入れたい。字幕がちゃっちい | 中心を測り直してロゴと一緒に動くように。生の音・効果音を追加。字幕を太字のせり上がりに |
| v3（Vlog 風） | もっと人が作った感じにしたい（映像が原因かも） | 色を自然に・粒子・手持ちの揺れ、画面録画風、手書きの書き込み、Reels 風字幕 |
| cm4（文字が主役） | （Claude だけで Pixel 風が作れるかの試作。2026-10-19） | 人を出さず、文字・アプリ画面・実データ・ロゴだけで構成 |
| cm4 v1 → v2 | 1週間の空きコマの部分はリアルな UI を使ってほしい（2026-10-20） | 抽象的なマスをやめ、アプリの実画面の表をカードにして見せる |
| cm4 v2 → v3 | 画面はいい感じ。音楽をもうちょっといい感じに（2026-10-20） | ウクレレ風の単純な合成音をやめ、はじいた弦・ベル・パッド・ベース・4つ打ちのポップに。場面に合わせて展開（ブレイク→盛り上がり）、残響・キックに合わせたうねり、-14 LUFS にそろえた |
| cm4 v3 → v4 | もっとゆったりしてもいいかも、ギター中心で（2026-10-20） | ハーフタイムのゆったりしたリズムに。ギターは弦の物理モデル＋胴鳴り、弾くタイミングと強さを少しずつずらし、指が弦をこする音も入れた。効果音は控えめに |
| cm4 v4 → v5 | ギターの音がナチュラルじゃない。もっとスムーズに（2026-10-20） | 原因は弦の合成法（Karplus-Strong）の音程が +6〜+20 セント高くずれていたこと、雑音から作る弾き始め、こすれ音・ミュートの入れすぎ。倍音の足し算に替えて音程のずれをほぼ 0 にし、立ち上がりを柔らかく、細工を減らした |

| cm5 v1 → v2 | 決めの言葉の紙に変なロゴが入っている／スマホを Apple のスマホに／報告の場面は、ふつうの使い方の説明に（2026-11-12） | ロゴ風の輪の図と名前を外し、言葉と下線だけに。スマホは平らな金属の枠・角の丸いガラス・細い縁（ロゴは映さない）。場面4は「〜6限」の札 → 教室を押す → 1週間のページ、場面5は時計が次の時限に進み「いま 水曜4限」に切り替わる |
| cm5（3D 広告） | 運営の企画文（机の上だけで7場面・青緑の1色・レーダーの輪でつなぐ）から作成（2026-11-12） | 企画文から変えた点：場面3〜5に短い字幕を足した（初見で意味が伝わるように）／スマホの画面は駿河台校舎のタブ（船橋のタブは隠し、7階以上の教室は映さない）／紙は「起き上がって本のように少し開く」／最後に「RoomRadar 空き教室検索」の文字 |

**次に良くするなら**
1. **人の映像を本物にする。** AI 生成の人物は、よく見ると分かる。v3 の構成のまま、7カットだけ運営メンバーがスマホで撮った5〜8秒の動画に差し替えるのがいちばん効く（顔を出したくなければ手元・後ろ姿でよい）。
2. AI 動画を作り直すなら `video/cm-ai/ai_prompts.md` の「前回わかったこと」を反映する（金色の光を避ける・PC のロゴなし・光の粒なし）。
3. 音楽は Instagram アプリの流行りの曲にすると投稿らしくなる（BGM なし版を使う）。
4. ナレーション（「空きコマ、どこ行く？」など）を入れるなら、運営の声をボイスメモで録って送ってもらう（自然な日本語の声はこちらで作れない）。
5. 投稿したら、どの版を出したか・反応（再生数・保存）をこの README に書き足すと、次の比較に使える。
