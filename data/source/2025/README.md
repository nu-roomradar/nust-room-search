# 2025年度（令和7年度）の時間割の原本を置く場所

まだ空。**教務ページから2025年度の時間割表が取れたら、ここに入れる。**

過去の年度を入れておくと、サイト上で年度を選んで「去年のこの時間、この教室は空いていたか」を
引けるようになる。検索の既定はいちばん新しい年度なので、ここに入れても今の検索結果は変わらない。

## 手順

1. https://www.kyoumu.cst.nihon-u.ac.jp/timetable/ から2025年度分をダウンロードする
   - 理工学部（14学科＋一般教育）／短期大学部／博士前期／博士後期の**全部**
   - 2026年度は合計49ファイルだった
2. ファイル名は**変えずに**このフォルダに置く（区分・学科・年度をファイル名から読んでいる）
3. Claude Code に「2025年度の原本を置いた」と伝える。DB の作り直しから確認まではこちらでやる

## 形式の注意

必要なのは **`1_理工学部_01_土木工学科_0_2025年_時間割表1面_....xls`** の形の、
曜日×時限のグリッド（人が読む時間割表）。シートが「前期」「後期」の2枚になっているもの。

教務ページで配布されている一覧形式のエクスポート（`1-01.xlsx` のような名前のもの）は
**別物なので置かない**。変換スクリプトが読めないうえ、学科名・科目名・教室名の
正規化前の情報が欠けている。

教務ページで過去年度が配布されていない場合は、無理に入れなくてよい。
年度選択は2026年度だけでも動く。

詳しくは `data/source/README.md` と `docs/OPERATIONS.md` の 6.
