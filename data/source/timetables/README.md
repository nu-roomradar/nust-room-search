# 時間割の原本置き場

`schedule_final.db`（検索の元データ）を作り直すための**原本ファイル**をここに置く。

`data/source/classroom_data.xlsx` などは原本ではなく集計結果で、**DB の 48% しか再現できない**。
学科名・科目名・教室名の正規化前の表記は、下の原本ファイルにしか無い。詳細は `docs/OPERATIONS.md` 6.

## 何を置くか — ファイル名は分かっている

現行 DB の作成時に使われたのは、教務ページで配布されている**学科ごとの時間割ファイル**:

```
1-01.xlsx  1-02.xlsx  1-03.xlsx  1-04.xlsx  1-05.xlsx
1-06.xlsx  1-07.xlsx  1-08.xlsx  1-09.xlsx  1-10.xlsx
1-12.xlsx  1-13.xlsx  1-14.xlsx  1-15.xlsx
```

14ファイル（**1-11 は欠番**）。各ファイルが1学科分で、船橋校舎と駿河台校舎の授業を両方含む。
`1-11.xlsx` も配布されていれば一緒に置いてほしい（現行 DB に入っていないだけかもしれない）。

配布元: https://www.kyoumu.cst.nihon-u.ac.jp/timetable/
（この環境からはネットワークポリシーで到達できないため、Claude 側ではダウンロードできない）

**ファイル名は変えずに置くこと。** 現行 DB の集計に `元ファイル` としてこの名前が残っており、突き合わせに使う。
番号と学科の対応が分かる場合は、下の対応表に書き足してほしい。

## 置き方

年度ごとにサブフォルダを切る:

```
data/source/timetables/
├── README.md      ← このファイル
├── 2026/          ← 現行 DB の元（前期・後期）
│   ├── 1-01.xlsx
│   └── ...
└── 2027/          ← 翌年度分はここに
```

xlsx が手に入らない場合は pdf / csv / html でもよい。形式が違っても解析できるか確認する。

## iPad からのアップロード手順（GitHub の Web 画面）

1. Safari で https://github.com/nu-roomradar/nust-room-search/tree/main/data/source/timetables を開く
2. 右上の **Add file → Upload files**
   （ボタンが出ないときは、アドレスバー左の「ぁあ」→ **デスクトップ用Webサイトを表示**）
3. **choose your files** →「ファイル」アプリから該当ファイルを選ぶ（複数選択可）
4. ページ下部は **Commit directly to the main branch** のまま **Commit changes**
5. Claude Code のチャットで「原本を置いた」と伝える

年度フォルダに入れたいときは、アップロード後にファイル名欄で `2026/1-01.xlsx` のように
スラッシュ付きに書き換えるとフォルダが自動で作られる。

上限: 1ファイル 25MB、1回のアップロードで 100 ファイルまで。時間割ファイルなら問題ない大きさ。

## 届いたら最初にやること

```
python scripts/inspect_timetable.py data/source/timetables/2026/
```

シート構成・列・ヘッダー行の位置・教室や曜日らしき列を報告する。
これを見てから `scripts/build_schedule_db.py`（再現スクリプト）を書く。
