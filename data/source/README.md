# 時間割の原本

`schedule_final.db`（空き教室検索の元データ）と `data/classes_2026.csv`（授業の生データ一覧）は、
どちらもここにある `.xls` から作られる。**ここが唯一の原本。**

## 置き方

**年度ごとのフォルダに入れる。**

```
data/source/
├── README.md
├── 2026/          ← いま使っている年度（49ファイル）
├── 2027/          ← 翌年度。公開されたらここに入れる（中の README に手順あり）
└── archive/       ← 使わない古いファイル
```

`build_schedule_db.py` と `export_classes.py` は、**原本が入っている年度フォルダを全部**読む。
DB は複数年度を同居させ、サイト上で年度を選べるようにしているため。
空の年度フォルダは飛ばして警告を出す。1年度だけにするなら `--year 2026`。

検索の既定は「いまの年度・いまの学期」なので、過去の年度を足しても今の検索結果は変わらない。

## 置いてあるもの

教務ページ https://www.kyoumu.cst.nihon-u.ac.jp/timetable/ が配布している時間割表。

```
<区分番号>_<区分名>_<学科番号>_<学科名>[_<コース>]_<年>年_時間割表N面_<timestamp>.xls
```

| 区分番号 | 区分 | 2026年度のファイル数 |
|---|---|---|
| 1 | 理工学部 | 16（14学科 ＋ 一般教育。交通システム工学科はコース別に2つ） |
| 2 | 短期大学部 | 3 |
| 3 | 博士前期 | 15 |
| 4 | 博士後期 | 15 |

計 49 ファイル。中身は曜日×時限のグリッドで、シートは「前期」「後期」の2枚。
**ファイル名は変えないこと**（区分・学科・年度をファイル名から読んでいる）。

短期大学部は船橋校舎を理工学部と共用しているので、入れないと短大の授業が入った教室を
「空き」と表示してしまう。必ず一緒に置く。

## 翌年度の入れ替え

1. 教務ページから全区分・全学科をダウンロードして、**その年度のフォルダ**に置く（例 `data/source/2027/`）
2. `python scripts/build_schedule_db.py --report` で差分を確認
3. `python -m unittest discover -s tests` が通ることを確認
4. `python scripts/build_schedule_db.py --replace` で差し替え（`.bak` が自動で作られる）
5. `python scripts/export_classes.py` で生データ一覧も更新（`data/classes_<年度>.csv` が増える）
6. コミットして push（Render が自動デプロイ）

詳しい手順と注意点は `docs/OPERATIONS.md` の 6.

iPad から置くときは、GitHub の Web 画面で **Add file → Upload files**。
ボタンが出ないときは Safari の「デスクトップ用Webサイトを表示」を有効にする。

## archive/

使わない古いファイル。消してはいないが、**変換には一切使わない**。

- `1-01.xlsx` 〜 `1-15.xlsx` — 令和7年度の別形式のエクスポート（一覧形式）。
  現行の時間割表とは形式も年度も違う。
- `classroom_data.xlsx` / `summry_classrooms.xlsx` — 上記から誰かが作った集計。
  原本ではないので、これだけでは DB を再現できない（占有スロットの48%しか導けなかった）。
