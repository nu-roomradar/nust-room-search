# 3D 広告「机の上」（縦 1080×1920・30秒・7場面）

2026-11-12、運営の企画文をもとに作成。夕方の空き教室の机の上だけで、時間割の紙 → 空きコマが光る → スマホ（アプリの実画面）→ ふつうの使い方（何限まで空いているか・教室の1週間）→ 時限が変わっても「いま」の空き → 決めの言葉 → ロゴと必須の表記、と進む。
完成版は `assets/instagram/cm/cm5-desk-3d-v2.mp4`（v1 は場面4・5が「実は使われていた」の報告と、時限の終わりで消える話だった。運営の意見で v2 に）。

## 作り方（この環境でそのまま作り直せる）

```bash
cd video/desk-3d
bash fetch_fonts.sh          # 書体（Noto Sans CJK JP・Syne。OFL）を fonts/ に
bash fetch_vendor.sh         # three.js 0.170.0（MIT）を npm から vendor/ に（CDN はこの環境から届かない）
# アプリの実画面を撮り直すとき（時刻を 水曜 14:40 に固定して起動 → 撮影）
python3 fakeapp.py 14:40 5057 &  python3 fakeapp.py 15:10 5058 &  ;  python3 capture.py  ;  pkill -f fakeapp.py  ;  rm -f ../../reports.db
python3 sheet.py 1.5,6.5,10.8,13.6,15.6,18.5,22.8,27 --scale 0.4 --cols 8   # 下書きのコマの一覧（renders/pv/sheet.jpg）
python3 render.py --out renders/frames --query rs=0.8                        # 本番（全900コマ・約26分。途中で止めても続きから。rs=0.8 は 3D だけ8割の大きさで描く）
python3 music.py                                                             # 音（自作）
bash encode.sh                                                               # コマと音をつないで mp4 に
```

- **HyperFrames ではなく自前の書き出し（`render.py`）にした理由**：3D（WebGL）をこの環境で描くと、GPU が無いので Chrome の中のソフトウェア描画（SwiftShader）になり、1コマに数秒かかる。途中で止めて続きから撮れる・コマごとに時間を測れる形が要ったので、`video/cm-ai` と同じ「1コマずつ撮る」方式にした。`index.html` は `hf-seek` も受けるので、HyperFrames から時刻を送ることもできる。
- 時刻 `t` だけで絵が決まる（`window.renderAt(t)`）。場面の切れ目は `scene.js` の先頭の `T` に集めてある。音（`music.py`）も同じ時刻に合わせている。
- 描いているもの：机（木の写真を貼った板）、紙（canvas で描いた時間割。架空の時間割）、光る札、レーダーの輪（机の面のシェーダー）、スマホ（アプリの実画面の写真を canvas に描いて貼る）、置き時計、鉛筆、ぼけて見える教室。光は「窓の形のスポットライト（桟の影つき）」。後処理は 浅いピント（自作）→ 光のにじみ → 色 → 粒子。

## 中身で確かめたこと

- **「水曜3限でも、24室が空き」**：`schedule_final.db` の 2026年度・後期。駿河台キャンパス（タワー・スコラ 38室＋駿河台校舎 26室＝64室）のうち、水曜3限に時間割上の授業が無いのは 24室（タワー・スコラ 12・駿河台校舎 12）。全曜日・全時限で最も少ないコマ。
- **スマホの画面**は本物のアプリ（駿河台校舎のタブ）。水曜 14:40 の一覧（3限・12室）→ 教室 705 を押したところ → 705 の1週間のページ → 15:10 に開き直した一覧（「いま 水曜4限」・14室）。時刻を固定して実際に操作して撮った。「〜6限」の札は「その時限まで続けて空き」の表示。
- **スマホの形**は平らな金属の枠・角の丸い黒いガラス・細い縁・上の黒い楕円（iPhone らしい見た目）。ロゴなどの印は付けていない（実在ブランドのロゴは映さない決まり）。
- 船橋校舎のタブは撮影時に隠した（`capture.py` の `HIDE`。学生課の依頼で近く外す予定の表示でもある）。画面はすべて駿河台校舎。7階以上の教室（学生課の依頼で外す予定）も映していない。
- 「予約」「確保」は使っていない。最後に必須の表記（学生課の文言）を約4.8秒出す。人の顔・大学のロゴ・看板・校舎の名前の看板は無い。

## 書き出しを速くするために分かったこと（次に 3D を作るとき用）

- この環境は GPU が無く、Chrome の中のソフトウェア描画になる。1コマは 1080×1920 そのままだと約4.5秒、3D だけ8割（`rs=0.8`）で約1.7秒。同時に2つ動かしても速くならない（もともと全部のコアを使う）。
- シェーダーの中で `exp(-大きな数)` のような極小の数を作ると、極端に遅くなる（1コマ10秒以上）。遠いところは計算せず 0 にする。
- テクスチャの異方性フィルタ（anisotropy）は 8 だと重い。2〜4 にする。影は、影を落とすものが動いたコマだけ作り直す。
- `pkill -f "desk-3d/render.py"` では止まらない（起動したときの書き方が `python3 render.py` だと名前に入らない）。`pkill -f render.py` で止め、残った Chrome も確かめる。

## その2「ポスターとドア」（`door.html`・`door.js`。縦 1080×1920・27秒）

2026-11-12、運営の構成案から作成。夕方の廊下で、掲示板の「どこ行く？」ポスター → スマホのカメラで QR を読み取る → 空き教室の一覧が出る →「705」が空いている → 友達3人の影が壁を通って 705 の教室に入っていく → ドアが閉まり、ドアにロゴと必須の表記。
完成版は `assets/instagram/cm/cm6-poster-door-v4.mp4`（v1 は後ろ姿の人形を映していた。運営の意見「人が違和感」で、v2 は姿を出さず影だけに。v3 はちらつきを抑えた。v4 は字幕を作り直した）。

```bash
python3 sheet.py 1,5.2,9,10.7,15.8,17.6,19.2,22 --scale 0.4 --cols 8 --page door.html      # 下書きのコマ
python3 render.py --page door.html --duration 27 --out renders/frames_door --query rs=0.8   # 本番（810コマ）
python3 music2.py && bash encode.sh door
```

- ポスターは実物のデータ（`assets/posters/claude-design/RoomRadar_poster_A4_2480x3508.png`）を掲示板に貼ってある。QR も実物どおり。
- スマホの「カメラの画面」は、ポスターの QR のまわりを拡大して描いたもの（黄色い角と「nu-roomradar.github.io」の札は iPhone のカメラの見た目に似せた自作）。実際の QR は紹介ページ（LP）が開き、そこから検索画面に進む。動画では短くするため、読み取ってすぐ一覧が出る形にしている（ポスターの文言「読み取るだけ。空き教室が一覧で出る。」に合わせた）。
- 一覧の画面は机の版と同じ実画面（水曜 14:40・駿河台校舎・12室）。教室の札「705」は、一覧で見つけた教室と同じ番号。
- **人の姿は映さない。** 影を落とすための人の形を置き、色も奥行きも描かない設定（`colorWrite: false`）にしてある。夕方の光で壁に、教室の明かりで床に、影だけが落ちる。足音は自作の音。実在の人物・AI 生成の映像は使っていない。
- スマホの画面は、四隅を透明にして本体の丸い角からはみ出さないようにしてある（v1 で四角い角が飛び出していた）。
- 共通の部品は `common.js`（`scene.js` から写したもの。`scene.js` は書き出し済みの版と揃えるため、そのままにしてある）。
- **ちらつき（チカチカ）を避ける**：とても明るい面（教室の中・窓）と暗い枠の境目、ドアのすき間のような細い強い光は、コマごとに明るさが暴れる。明るさは 1.5 くらいまでに抑え、すき間はふさぐ。ぼかしの粒（`dof.params.seed`）はコマごとに変えない。確かめ方は、前後のコマの平均との差を場面ごとに測る（1コマだけ跳ねる所が赤く出る）。
- **字幕**は、太い白文字を画面にかぶせると安っぽく見える（運営の意見）。小さな見出し＋短い言葉を、すりガラス風の札（`.cap.card`。`backdrop-filter` はこの書き出しでも効く）に載せる。一部だけ直すときは、そのコマだけ消して `render.py --start … --end …` で書き出し直せる（時刻だけで絵が決まるので、前後とつながる）。
