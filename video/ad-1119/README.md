# 広告ふうの静止画（2026-11-19）

運営の依頼「こういう広告のようなもの（ドリップコーヒーの縦長の広告の見本）を、縛りなしで。画像の中はキャッチコピーだけ」。

完成版（1080×1350、Instagram のフィードの縦長）は `assets/instagram/ad/`：

| ファイル | キャッチコピー |
|---|---|
| `ad-desk-90min.png` | 九十分の、／居場所。（おすすめ） |
| `ad-desk-ikisaki.png` | 空きコマの、／行き先。 |
| `ad-desk-sagasu.png` | 探す時間を、／過ごす時間に。 |

- 絵：暗い紺の台の上に、架空の時間割の紙（空きコマに青い印）と、アプリの実画面を映したスマホ、鉛筆、マグ。左から低い暖かい光だけを当てた。Blender 4.5（Cycles、160サンプル、約3分）。`scene.py still final`。
- 試した方向：`still`（机の上の静物。これにした）、`room`（夕方の誰もいない教室に窓から日が差す）、`door`（暗い廊下で少し開いた扉から光がこぼれる）。どれも `scene.py <方向> preview` で下書きを描ける。
- 文字：明朝（Noto Serif CJK JP、OFL）の縦書きを右上に。左上に小さく「RoomRadar」（Syne）。`compose.py <背景> "<1行目>|<2行目>" <出力>`。書体のファイルは大きいのでリポジトリに入れない（notofonts/noto-cjk の Serif/OTF/Japanese から取る）。
- スマホは平らな金属の枠と黒いガラスだけ（ブランドの印なし）。時間割は架空（授業名は読めない灰色の棒）。人の顔・実在のロゴ・写真素材は使っていない。
- 画面の中は運営の注文どおりキャッチコピーだけ。**投稿するときはキャプションに「試験運用中・大学公式ではない」の文と #日大生プロジェクト を入れる**（CLAUDE.md ルール1・2）。

## キャッチコピーの候補（10案）

1. 九十分の、居場所。
2. 空きコマの、行き先。
3. 探す時間を、過ごす時間に。
4. 次の九十分を、どこで。
5. 空きコマに、ひと部屋。
6. 歩き回らない、空きコマ。
7. 教室探しを、終わらせる。
8. いまの九十分に、ちょうどいい場所。
9. 空いている教室は、すぐそこに。
10. 時間割のすき間に、行き先を。

（「静か」「集中」「自習室」を売りにしない・「予約」「確保」と書かない、の決まりに合わせて選んだ）

## やり直し（2026-11-19 夕方。運営の指示「15時の分をもう一回」）

1回目は、物が画面の端で切れ、主役のスマホが小さかった。構図から作り直し、3つの方向をどれも本番の画質（Cycles 256サンプル）で仕上げた。完成版は `assets/instagram/ad/`：

| ファイル | 絵 | キャッチコピー |
|---|---|---|
| `ad2-hero-90min.png`（おすすめ） | 切れ目のない紺の背景（撮影用のホリゾント）に、3冊の本に立てかけたスマホ（アプリの実画面）。手前に鉛筆と時間割のカード、左に紺のマグ。左から低いあたたかい光、背景に青い明るみ。見本の構図にいちばん近い | 九十分の、／居場所。 |
| `ad2-door-mayowanai.png` | 暗い廊下。半分開いた教室の扉から、あたたかい光が床にこぼれる。すき間から机が見える | 扉の前で、／迷わない。 |
| `ad2-room-ikisaki.png` | 夕方の教室。手前の机に本に立てかけたスマホと鉛筆、奥はぼけた机の列と、窓から差す日の光 | 空きコマに、／行き先を。 |

- 作り方：`scene2.py <hero|door|room> final` → `compose.py <背景> "<1行目>|<2行目>" <出力> [side=left] [mark=0] [size=76] [shade=0.5]`。コピーの差し替えは compose だけですぐできる。
- キャッチコピーの候補（出し直し）：九十分の、居場所。／空きコマに、行き先を。／扉の前で、迷わない。／行き先のある、空きコマ。／次の一限まで、ここにいる。／歩き回らない、空きコマ。／探す時間を、過ごす時間に。／時間割のすきまに、あかりを。
- 1回目の3枚（`ad-desk-*.png`）も残してある。
